# Dev Trial 006

This trial is an example-locked schema-adherence smoke for the harder subset.

## Goal

Test whether adding:

- a minimal valid JSON skeleton
- one valid micro-example
- a final schema checklist

is enough to raise `schema_validity` above zero.

- 3 harder tasks
- 2 groups
- 1 repeat per group

Tasks:
- `seed_zh_0007`
- `seed_en_0011`
- `seed_mix_0009`

Groups:
