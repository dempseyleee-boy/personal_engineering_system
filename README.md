# Personal Engineering System

This package contains a reusable personal engineering optimization system for Agent-based project work.

## Structure

```text
personal_engineering_system/
├── 00_PERSONAL_ENGINEERING_OPTIMIZATION_PATH.md
├── skills/
├── templates/
├── context/
├── task_context/
└── reports/
```

## Start Here

1. Read `00_PERSONAL_ENGINEERING_OPTIMIZATION_PATH.md`.
2. Read `skills/PROJECT_BOOTSTRAP_SKILL.md`.
3. Use `templates/` to generate project-specific files in `context/`.
4. For complex tasks, generate files in `task_context/`.
5. After tasks, use `templates/closing/30_TASK_CLOSING_CHECKLIST.md`.
